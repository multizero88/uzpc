> **UZPC (BuildHub)** — легковесный, быстрый и современный веб-конфигуратор персональных компьютеров с мультивалютным калькулятором (USD, UZS, RUB), умным автодополнением комплектующих, интеграцией статистики Steam Hardware Survey, каталогом Топ-100 деталей и лентой IT-новостей.

Работает полностью на стороне клиента (Vanilla JS), без тяжёлых фреймворков и необходимости сложного бэкенда — запускается прямо в браузере или мгновенно разворачивается через **GitHub Pages**.

---

## 🌟 Основные возможности

### 🛠️ 1. Умный конфигуратор ПК
- **Пошаговая сборка системы:** Процессор, Видеокарта, Оперативная память, SSD / Накопители, Корпус, Материнская плата, Блок питания, Охлаждение, Корпусные вентиляторы.
- **Встроенная база комплектующих:** Быстрый автокомплит при вводе названия с подсказками цен и характеристик (включая линейки AMD Ryzen 9000/7000, NVIDIA GeForce RTX 50/40, Intel Core Ultra/14-gen, DDR5, PCIe 4.0/5.0).
- **Ссылки на магазины:** Возможность прикреплять ссылки на товары из любых магазинов и маркетплейсов (DNS, Uzum, Wildberries, Ozon, OLX и др.).
- **Гибкое управление:** Регулировка количества (например, для вентиляторов или модулей памяти), удаление и добавление любых позиций.

### 💱 2. Мультивалютный переключатель (UZS / USD / RUB)
- Мгновенный пересчёт стоимости всей сборки и цен комплектующих:
  - **$ USD** (Доллары США)
  - **UZS сум** (Узбекские сумы) — адаптировано для рынка Узбекистана
  - **₽ RUB** (Российские рубли)
- Автоматическое форматирование разрядов чисел для комфортного восприятия.

### 💾 3. Сохранение сборок и социальный фид
- Сохранение созданных сборок в локальное хранилище (`localStorage`).
- Каталог готовых сборок с фильтрами («Новые», «Популярные», «По лайкам»).
- Интерактивные лайки, счётчики комментариев и бейджи (`HOT`, `NEW`).

### 📊 4. Каталог и аналитика железа (Steam Hardware Survey)
- Наглядная инфографика популярных разрешений экранов, долей процессоров AMD/Intel, видеокарт NVIDIA/AMD и объёмов оперативной памяти на основе данных опроса миллионов геймеров.
- Рейтинг наиболее часто используемых видеокарт, процессоров, ОЗУ и накопителей с процентными шкалами.

### 🏆 5. Таблица «Топ-100 комплектующих»
- Сводная интерактивная таблица популярных товаров с маркетплейсов.
- Фильтрация по типам (CPU, GPU, RAM, SSD, Мат. платы, БП, Кулеры).
- Поиск по названию в реальном времени.
- Сортировка по пользовательскому рейтингу (⭐) и числу отзывов (💬).
- Прямой переход к карточкам товаров.

### 📰 6. Интеграция IT-новостей
- Лента актуальных новостей из ведущих профильных изданий: **3DNews**, **iXBT**, **Overclockers**.
- Подгрузка свежих материалов через RSS-to-JSON в режиме реального времени.

## 🚀 Быстрый старт

Проект не требует Node.js, npm или сборщиков — он готов к работе прямо «из коробки».

### Локальный запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/multizero88/uzpc.git
   cd uzpc
   ```

2. Откройте файл `index.html` в любом современном браузере:
   - Дважды кликните по `index.html`
   - Или запустите локальный сервер (например, расширение *Live Server* в VS Code или Python):
     ```bash
     python -m http.server 8000
     ```
     После чего перейдите по адресу: [http://localhost:8000](http://localhost:8000)

## 🌐 Публикация на GitHub Pages (в 1 клик)

Вы можете опубликовать проект в интернете абсолютно бесплатно:

1. Откройте репозиторий **multizero88/uzpc** на GitHub.
2. Перейдите во вкладку **Settings** -> **Pages** (в левом меню).
3. В разделе **Build and deployment** -> **Branch** выберите ветку `main` и папку `/(root)`.
4. Нажмите кнопку **Save**.
5. Через 1-2 минуты ваш сайт будет доступен по ссылке:
   ```
   https://multizero88.github.io/uzpc/
   ```

## 🛠️ Стек технологий

- **HTML5** — семантическая разметка, структура вкладок (SPA без перезагрузки)
- **CSS3 (Custom Properties / Flexbox / Grid)** — отзывчивый интерфейс, неоновые эффекты, кастомные бейджи и скроллбары
- **Vanilla JavaScript (ES6+)** — динамический рендеринг, автокомплит, мультивалютный калькулятор, работа с `localStorage`, парсинг RSS
- **Google Fonts** — Rajdhani, Noto Sans
- **RSS2JSON API** — интеграция новостей без собственного бэкенда
